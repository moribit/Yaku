# Question Bank ルールレビュー台帳

問題データは人間によるルールレビューが必要。構造validationとAPI採点testは、役の正しさを証明しません。

全35問は実装時に牌の分解・context・複合役を検討したfixtureです。独立した人間のレビューは未実施。以下のチェックに沿い、reviewer・日付・指摘と修正を記録してください。公開教材の答えを確定する際にこの手順を実施します。

| 問題 | 確認対象 | 独立レビュー |
|---|---|---|
| b-01〜b-15 | 基本8役、立直表示、役牌の自風、門前、複合役 | 未実施 |
| i-01〜i-10 | 三色・通貫・全帯・暗刻・小三元・混一色 | 未実施 |
| a-01〜a-10 | 複合全役、役の排他、副露ツモ、ロンで暗刻を数えないこと | 未実施 |

- 14牌相当とphysical copiesに加え、実際に和了形へ分解可能か。
- 和了牌を1枚除いた13牌から、記述した待ちが成立するか。
- contextの場風／自風／門前／立直／ツモ条件と役が一致するか。
- primaryだけでなく、成立する複合役がすべてcorrectにあるか。
- 七対子と一盃口／二盃口、混一色と清一色、混全帯么九と純全帯么九の排他。
- 別の有効な面子分解で成立役が変わる場合、その問題を避けるか最大点の分解を明示するか。
- distractorが実際に不成立か。すべての解説がcontextと一致するか。

初期Question Bankでは特殊状況役・槓・役満はQuizに出題しません。Catalogの例は役の形を示すもので、牌姿単独でcontextを含む全成立役を表すものではありません。

自由入力機能追加時に、独立した期待値として全35問と役判定結果を比較するtestを追加しました。一致は機械的な検査の証拠であり、人間による独立レビュー完了の代替にはしません。
